## How to use
- Add one row for every art asset or sprite sheet used in the project.
- Keep `Status` as `TODO` until source and license are verified.
- When verified, set `Status` to `Verified`.
- If attribution text is required, copy exact wording into `Required Attribution`.

## Fields
- `Asset Path`: Path in this repo.
- `Source`: Artist, pack name, marketplace page, or URL.
- `License`: License type (CC0, CC-BY 4.0, commercial EULA, custom, etc.).
- `Required Attribution`: Exact credit text required by the license.
- `Used In`: Where it appears in game.
- `Status`: `TODO` or `Verified`.
- `Notes`: Any extra detail (purchase receipt, terms, edits made, etc.).
